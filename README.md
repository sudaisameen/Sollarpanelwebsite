# Solvex - Renewable Energy & Solar Solutions Website ☀️

**Solvex** is a modern, high-performance frontend web application designed for a solar energy and manufacturing company. It focuses on clean UI/UX, smooth animations, and seamless responsiveness across all devices.

## 🚀 Features
* **Responsive Navbar & Sidebar:** Custom mobile drawer with a 60% screen width, smooth slide animation, and click-outside dismissal.
* **GSAP Animations:** Implemented ScrollTrigger and timelines for stunning entrance and scroll-based animations.
* **Modern UI Design:** Built with a professional color theme (Black, White, and vibrant Green `#00D47E`).
* **Direct WhatsApp Integration:** Quick-action buttons enabling users to connect instantly for inquiries.
* **Optimized Performance:** Clean component structure using React.js and CSS Modules.

## 🛠️ Tech Stack
* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** CSS Modules
* **Animations:** GSAP (GreenSock Animation Platform) & ScrollTrigger
* **Icons & Assets:** Custom vector graphics and optimized imagery
